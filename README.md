# Food Delivery Web Application

## Overview

Food Delivery Web Application is a Java-based web platform that allows users to register, log in, browse food items, place orders, select payment methods, and manage their order history. The application is developed using Java Enterprise technologies and follows a structured MVC architecture.

---

## Features

* User Registration and Authentication
* Secure Login System
* Food Menu Browsing
* Place Food Orders
* Order History Management
* Payment Method Selection
* Database Integration with MySQL
* Session Management

---

---

## Project Architecture

```text
JSP Pages (Frontend)
        ↓
Servlets (Controller)
        ↓
DAO Layer
        ↓
Hibernate ORM
        ↓
MySQL Database
```
